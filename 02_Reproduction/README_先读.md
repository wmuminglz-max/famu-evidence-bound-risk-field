# 复现指南

[English](README.en.md) · [仓库概览](../README.md)

本目录提供论文实验的代码、协议、脱敏输入、评分键和归档预测，用于检查方法实现与复算结果。

## 快速开始

在本目录中使用 Python 3.10 或更高版本执行：

```bash
python -B tools/verify_release.py
python -B tools/recompute_results.py
```

两个工具仅依赖 Python 标准库。完整性核验检查文件 SHA256、数据格式、题目引用和证据位置；成绩复算读取归档预测与评分键，输出 `validation/recomputed_results.json`。先核验，再复算；如需保持文件清单的校验状态，可在目录副本中执行成绩复算。

## 复现范围

1. **复算归档成绩：** 使用包内预测和评分键，无需模型权重或 GPU。
2. **在脱敏输入上训练或推理：** 需配套模型与环境，结果应作为派生数据上的新实验报告。
3. **精确重跑原始实验：** 需受控原始权重、缓存、未改动输入及对应环境。

V5 对应实验一，V8 对应实验二。各版本应使用自己的冻结代码和协议。评测需保留样本组、种子和任务分母；完整答题与状态专项的指标分别解释。

## 材料范围

仓库提供去标识化派生材料，身份映射、原始合同附件、专家签认原件、原始权重和特征缓存属于受控对象。对象清单提供核对所需的用途、大小、SHA256 和校验来源。第三方材料适用其原有许可与使用条件。
