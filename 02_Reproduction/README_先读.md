## 从这里开始

在本文件夹中使用Python 3.10或更高版本执行以下命令。仅用标准库，不联网，不加载模型，不启动训练。

```bash
python tools/verify_release.py
python tools/recompute_results.py
```

第一条核验逐文件SHA256、数据格式、题目引用和证据位置。第二条从包内归档预测复算V5、V8和真实材料主要成绩，输出`validation/recomputed_results.json`。这些是历史结果的评分复算，不是在脱敏输入上重新生成预测。

## 三种复现范围

1. **成绩复算。** 用包内归档预测和评分键核对主要正确数、证据F1及联合正确率，不需要GPU。
2. **脱敏输入上的再运行。** 配套模型和环境可开展新训练或推理，但文字已改变，结果应作为派生数据上的新实验单独报告。
3. **原始实验精确重跑。** 需取得受控原始权重、缓存、未改动输入并对齐环境。本次没有重新执行GPU训练。

原工作区及原始材料未被修改。指纹核验不能证明模型遗忘训练内容，因此按用户选择排除了所有原始参数和可能携带训练信息的向量缓存。
