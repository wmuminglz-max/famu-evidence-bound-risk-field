# R11：连续证据跨度与训练材料回放

[English](R11_results.en.md) · [复现指南](../../README_先读.md)

R11 比较逐 token 选择与连续跨度选择，并考察加入旧训练材料回放的影响。四种训练配置分别使用 17、29、43 三个种子，共 12 组训练。归档核查涵盖 24 个完整检查点、360 个预测集和 12 个模型的 CPU 加载检查。

**各比较均未通过“三个种子共同改善且旧任务不退化”的预定门槛。** 以下结果应结合新场景、三种表述、历史回归和证据指标一起解释。

## 配置与评测

TOKEN 逐 token 选择原文，可能产生不连续片段；SPAN 预测段落类别和一个连续起止区间，并保护日期、金额的匹配边界。SPAN 同时改变起止点监督与边界解码，因此属于表示方法的整体对照。保留完整数字不保证选中正确日期或完成正确推理。

NEW 使用本轮段落，MIX 加入 R10 训练段落与历史训练正例的完整段落。历史未知关系或全无关关系不被额外标成非当前段落。四种配置在同一种子下使用相同的冻结编码器、rank 8 / alpha 16 适配器、5 输出头初始化与组内采样顺序。原 R8 词汇关系头、阈值和 query gate 保持冻结。R8_FROZEN 与 R10_SELECT 为零更新对照。

## 训练实现

历史运行在首次反传前遇到变量名冲突：LoRA 模块列表覆盖了段落起止点 `targets`。该问题在零优化器更新时通过分离变量修复，数据、损失、初始化、优化器、曝光及训练终点保持不变。精确重跑应核对对应的修复实现和执行指纹，启动前完成反传预检查；本仓库不包含原现场的专用恢复脚本。
