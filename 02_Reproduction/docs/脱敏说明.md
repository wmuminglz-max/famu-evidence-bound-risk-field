# 脱敏范围与复现影响

[English](deidentification.en.md) · [复现指南](../README_先读.md)

## 身份信息与任务信息

真实主体使用稳定代号，保持其在合同、题目、标准答案和模型回答中的对应关系。姓名、机构及简称、联系方式、详细地址、银行账户、登记号码、合同标识、案号、来源链接、本机用户名和服务器位置均经过检查与替换。身份映射属于受控材料。

签署联系页中与题目无关的人员和账户栏已删除；参与审查的条款及页码予以保留。仓库不包含原始 Word、PDF、Excel、图像、合同附件、专家签认附件、原始模型参数、优化器状态或特征缓存。

分类标签、随机种子、更新数、读取次数、字段与证据编号、数据划分、充分证据组和数值评分予以保留。计算必需的金额、日期、比例和合同逻辑关系，以及公开法律名称与条号予以保留。模拟场景中的虚构名称用于区分主体，不同当事人保持不同代号。

## 证据位置与指纹

实体替换后的实验一证据字符位置已经重新定位并校验。真实题输入哈希与评分键、归档生成和解析结果中的输入指纹保持一致。受控原件与仓库文件的整文件 SHA256 分别记录。

文字变化可能影响分词、隐藏向量与预测。原始特征缓存对应原始输入；包内 `raw` 字段保留的是去标识化后的历史生成字符串。日志中的输入 token 数和耗时描述原始运行。在脱敏文本上训练或推理，应另行记录输入指纹和结果。

## 标注与结果解释

专家答案对应原始题目的复核，E01/E02 为匿名复核编号。去标识化材料保留原有答案、预测、随机种子与评分口径；成绩复算用于检查归档结果。数据中的错误预测仍按原记录保留。

金额、日期或相似公开材料仍可能支持来源关联。去除直接身份信息不构成不可逆匿名化证明，也不替代第三方材料的许可与使用条件。

## 学生模型的原文切片

真实材料学生模型按证据原文分窗。正文经过替换的证据，其原始窗口切片属于受控内容，位置以 `original_start/original_end` 标识；这些坐标对应原始文字。窗口编号、所属证据编号、模型判断和置信度予以保留，可按证据编号查看脱敏后的完整证据。

正文未改变的证据保留历史切片，并逐条核对位置。分窗清单见 `experiments/real_eval/config/student_input_adapter_audit.json`。答案、引用的证据编号和评分口径保持一致。
