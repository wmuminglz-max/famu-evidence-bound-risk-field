# 脱敏范围与复现影响

真实主体采用稳定代号，保留同一主体在合同、题目、标准答案和模型回答中的对应关系。姓名、机构及简称、联系方式、详细地址、银行账户、登记号码、合同标识、案号、来源链接、本机用户名和服务器位置均进行检查和替换。身份映射只留在本地构建目录，未放入共享包。

合同签署联系页中不参与问题判断的人员及账户栏已删除，保留页码和参与审查的条款。原始Word、PDF、Excel、图像、旧压缩包、专家签认附件、优化器状态、原始参数和特征缓存均未复制，避免附件绕过文本处理。

分类标签、随机种子、更新数、读取次数、字段和证据编号、数据划分、充分证据组及数值评分保留。题目计算必需的金额、日期、比例和合同逻辑关系保留。公开法律名称和条号不作为身份信息任意修改。模拟场景中的虚构名称原则上保留，避免把主体辨别任务消掉。不同当事人的代号相互区分，不合并为同一个“某人”。

替换实体后，实验一证据字符位置重新定位并检查。真实题输入哈希重新计算，评分键、归档生成和解析结果中的输入指纹同步更新。原件整文件SHA256与交付SHA256分别保存。

文字变化可能影响分词、隐藏向量和预测。既有特征缓存不能作为脱敏文字已经重新提取的表示；脱敏输入上的新训练也不保证复现原始输出。包内`raw`字段是对历史生成字符串去标识后的保留，不代表新生成。原始输入token数和耗时仍是历史记录，不是本次脱敏输入的测量。

本次没有新增训练、重新标注法律事实或把错误答案修成正确答案，没有用最佳种子替代全部结果。复算程序检查主要成绩是否维持原记录。E01/E02保留为匿名复核编号，原专家复核针对原题，并非本次脱敏后重新复核。

本包不包含原始参数，也未声称消除了模型记忆。去掉直接身份信息不等于证明无法从金额、日期或相似公开材料辨认来源。本包未声称完成法律意义上不可逆匿名化认证，也不替代第三方材料许可。原始来源和授权档案保留在本地，未公开身份映射和签认原件。

## 学生模型原始切片的位置

真实材料学生模型使用原文分窗。对于正文发生去标识化改动的证据，轨迹中的原始切片文字不再公开，起止位置改为`original_start/original_end`，明确属于受控原文，不用于定位脱敏文字。原窗口编号、所属证据编号、模型判断和置信度保留；可按证据编号查看脱敏后的完整证据。未发生改动的证据保留历史切片，并逐条核对位置。历史分窗清单见`experiments/real_eval/config/student_input_adapter_audit.json`。本处理不更改答案、引用证据编号或评分。
