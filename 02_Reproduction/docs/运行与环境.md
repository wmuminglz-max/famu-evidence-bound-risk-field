# 运行层次和环境

## 无模型成绩复算

根目录执行`python tools/recompute_results.py`，只读归档预测并使用原评分逻辑核对主要结果。R11保留全部配置和配对版本，不能只展示历史题满分。

## 原始模型推理

取得受控适配器及配套底座后，先按`models/`清单核验。原始底座加未合并适配器是实验二参考对象。历史合并导出的BF16模型不能无条件替代参考模型，本包未公开或重新验证大型合并模型。

历史环境主要为Linux/CUDA、Python 3.10、PyTorch 2.11.0+cu130、Transformers 5.8.0、PEFT 0.21.1、Accelerate 1.15.0、safetensors 0.7.0；27B用bitsandbytes 0.50.2执行NF4双重量化加载。各配置以实际协议及环境记录为准。本次文件和评分核查不等于重新执行GPU训练。

V8可见输入只含`scope`、`fields`、`rule`、`evidence`，使用`famu_v8.messages()`生成提示，`decode()`解析并计算。不能把`target`、`states`或标准`bindings`发给模型。状态专项和完整答题模式使用不同提示，不能混用分母。

## 重新训练入口

在隔离目录准备受控底座和初始化适配器。以下是调用形式，模型路径由使用者配置。

```bash
cd experiments/v5
python scripts/run_famu_v5.py --base /path/to/base9b --data training_data/famu_v5_20261004 --out /path/to/new_v5_run
cd ../v8
python scripts/run_famu_v8.py --base /path/to/base9b --init /path/to/shared_initial_adapter --data training_data/famu_v8_20261005 --out /path/to/new_v8_run
```

这些入口执行训练，不能把`--out`指向共享包的归档结果。用脱敏文本重新提取V5特征或训练V8属于新的运行，不能将旧数据哈希视为本次输入完全相同的证明。V8每个分支的实际训练计划和权重保存在相应协议中。

各历史代码版本分别保存。机器路径已改为占位路径，通用入口通过`--base`、`--data`和`--out`配置。27B专家路由和学生关系模块需要自己的冻结实现，不能仅用标准LoRA加载方式代替。历史部署、下载和服务器脚本不作为自动安装入口。
