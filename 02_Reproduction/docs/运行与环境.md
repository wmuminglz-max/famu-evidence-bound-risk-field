# 运行与环境

[English](execution_and_environment.en.md) · [复现指南](../README_先读.md)

## 无模型成绩复算

在 `02_Reproduction/` 中使用 Python 3.10 或更高版本：

```bash
python -B tools/verify_release.py
python -B tools/recompute_results.py
```

工具仅依赖标准库，读取归档预测并按评分逻辑核对主要成绩。先核验文件完整性；复算会写入 `validation/recomputed_results.json`，需要保持校验状态时应使用工作副本。R11 的结果包括全部配置、新场景的三种表述和历史回归，应结合阅读。

## 原始模型推理

取得受控适配器和配套底座后，先按 `models/` 清单核验版本和指纹。实验二的参考对象是原始底座加未合并适配器；使用其他导出形式时需要独立验证其等价性。

归档实验的主要环境为 Linux/CUDA、Python 3.10、PyTorch 2.11.0+cu130、Transformers 5.8.0、PEFT 0.21.1、Accelerate 1.15.0 和 safetensors 0.7.0。27B 使用 bitsandbytes 0.50.2 进行 NF4 双重量化加载。具体版本与加载方式以各配置的协议和环境记录为准。

V8 可见输入由 `scope`、`fields`、`rule` 和 `evidence` 组成，通过 `famu_v8.messages()` 生成提示，使用 `decode()` 解析。`target`、`states` 与标准 `bindings` 用于监督或评分。完整答题和状态专项使用不同提示，分别按其任务分母报告成绩。

## 训练入口

为受控底座、初始化适配器和新输出准备独立路径。从 `02_Reproduction/` 执行：

```bash
cd experiments/v5
python scripts/run_famu_v5.py --base /path/to/base9b --data training_data/famu_v5_20261004 --out /path/to/new_v5_run
cd ../v8
python scripts/run_famu_v8.py --base /path/to/base9b --init /path/to/shared_initial_adapter --data training_data/famu_v8_20261005 --out /path/to/new_v8_run
```

这些入口执行训练，`--out` 应指向新的工作目录。重新提取脱敏文本特征或在脱敏文本上训练属于新运行，应记录实际输入、代码和对象指纹。V8 分支的训练计划和样本权重见各自协议。

各历史版本使用自己的冻结实现。27B 专家路由与学生关系模块包含专用逻辑，需使用相应实现与配置。底座、数据和输出位置通过 `--base`、`--data` 和 `--out` 配置。

## 结果解释

实验一 M3 相对 M0 提高 46.22 个百分点，同时须报告 31 道未知题在三个种子下分别答对 2、3、4 道的结果。实验二的 144 题满分对应受控实验设置。真实材料正式主实验为 17 题、53 项、5 个来源组。学生模型应同时报告长句、短句、改序和历史回归，详见 [R11 结果](../experiments/student/R11_中文结果_连续跨度与训练回放.md)。
