# 数据集说明

[English](README.en.md) · [仓库概览](../README.md)

本目录提供论文实验使用的脱敏数据、标注、样本划分和来源索引。

## 数据组成

| 目录 | 内容与规模 |
|---|---|
| `01_Professional_Training_Data/` | 77 条专业训练任务、9 条内部开发任务、1,657 条劳动辅助训练任务。 |
| `02_Experiment_1_Conditional_Judgment/` | 1,213 条混合任务记录、576 条配对关系及 256 条新表述压力测试记录。 |
| `03_Experiment_2_Evidence_Binding/` | 672 条合成场景：训练 432 条、开发 96 条、测试 144 条；另含 77 条专业回放、9 条历史回归及冻结版本中的专业数据。 |
| `04_Real_Material_Evaluation/` | `public_inputs.jsonl` 提供 28 题输入，`gold_keys.jsonl` 提供 87 个评分项的答案与充分证据组；正式主实验为其中 17 题、53 项、5 个来源组。 |
| `05_Student_Model_Data/` | 关系对、段落与片段标注、新场景、历史场景及回归数据；`new_scenes.json` 含训练 1,152 条、开发 72 条，长句、短句、改序测试各 96 条。 |

[数据文件清单](数据文件清单.csv)列出逐文件记录数、内部集合和划分统计；[样本划分与编号](样本划分与编号.jsonl)列出样本编号、划分、组编号和条件顺序。空的划分字段表示原文件未指定划分。真实材料输入的划分与对应标准答案关联。

## 输入、标注与评测

JSONL 每个非空行是一条记录；JSON 文件可能包含数组或按内部集合组织的记录。`target`、`states`、标准 `bindings` 和标准答案用于监督或评分，应与测试时模型输入分开。真实材料评测分别读取输入文件和答案文件。

同一批样本可能用于多个实验或以不同表述保存。统计独立样本时，应依据 `pair_group` 等组编号去重，并保留原有训练、开发、测试划分。实验一的 1,213 条混合记录包含多种任务；真实材料的 28 题、87 项是完整集合，正式主实验的规模为 17 题、53 项。专业数据中的 9 条任务在后续实验中用于历史回归。

## 脱敏与来源

姓名、机构和来源使用稳定代号；直接联系方式、详细地址、银行账户和登记号码等已处理。判断所需的日期、金额、比例和逻辑关系予以保留。详细范围见[脱敏说明](../02_Reproduction/docs/脱敏说明.md)。

脱敏文本与原始实验输入存在文字差异。在这些文本上训练或推理，应报告为派生数据上的新实验。专家答案对应原始题目的复核；保留的金额和日期仍可能支持来源关联。

[文件来源与校验](文件来源与校验.json)记录数据文件在复现材料中的位置与指纹。[MANIFEST_SHA256.json](MANIFEST_SHA256.json)列出本目录文件的大小与 SHA256，清单自身除外。各实验数据目录中的 `manifest.json` 描述相应实验的数据组织方式。

训练协议、评分脚本、代码和模型版本信息见[复现指南](../02_Reproduction/README_先读.md)。第三方数据适用其原有许可与使用条件。
