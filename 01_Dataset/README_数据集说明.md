# 法眸智审数据集 · 对外共享脱敏版

本文件夹专门存放论文实验使用的数据和标注，整理日期为2026年10月16日。所有数据均从已经整理的脱敏复现包逐字节复制，内容和原有划分没有再次修改。

## 文件夹内容

| 文件夹 | 内容与规模 |
|---|---|
| `01_Professional_Training_Data` | 77条专业训练任务、9条内部开发任务、1,657条劳动辅助训练任务 |
| `02_Experiment_1_Conditional_Judgment` | 1,213条混合任务记录及576条配对关系；另有256条新表述压力测试记录 |
| `03_Experiment_2_Evidence_Binding` | 672条合成场景：训练432条、开发96条、测试144条；另保留77条专业回放、9条历史回归及冻结版本中的专业数据副本 |
| `04_Real_Material_Evaluation` | `public_inputs.jsonl`为28道题的输入，`gold_keys.jsonl`为对应标准答案和充分证据组。正式主实验是其中17题、53个评分项，其余为开发题和另一类判断题 |
| `05_Student_Model_Data` | 学生模型训练关系对、段落及片段标注、新场景、历史场景和各轮回归数据。`new_scenes.json`包含训练1,152条、开发72条，以及长句、短句、改序测试各96条 |

逐文件记录数、内部集合和划分统计见`数据文件清单.csv`，可用Excel打开。`样本划分与编号.jsonl`按文件、内部集合和行号列出样本编号、原有划分、组编号及条件顺序；空的划分表示原文件没有该字段，未擅自补成训练或测试。真实材料输入的划分来自对应标准答案库。

## 使用时需要区分的内容

JSONL每行是一条记录；JSON文件可能是记录数组，也可能按内部集合组织。数据中的`target`、`states`、标准`bindings`和标准答案属于监督或评分信息，不能拼入测试时的模型输入。真实材料评测应分别读取输入文件和标准答案文件。

同一批材料可能被多个实验使用。专业数据副本、回放数据和历史场景按归档版本保留；它们不是新增独立样本，不能将所有文件的记录数直接相加作为数据集总规模。长句、短句、改序版本也可能来自同一母题，必须保留`pair_group`或其他原有组编号。

实验一的1,213条记录包含多种任务，并非1,213道独立人工标注的合同审查题。真实材料文件共28题、87个评分项，不能将这一总量写成正式主实验规模。专业数据中的9条任务在后续实验被用作历史回归，应按各实验协议解释用途。

## 脱敏及校验

本目录延续前一版脱敏处理：真实姓名、机构和来源采用稳定代号，直接联系方式、详细地址、银行账户、登记号码等已经处理；题目判断必需的日期、金额、比例和逻辑关系保留。这里未包含身份映射、原始合同附件、专家签认原件、模型权重、特征缓存、代码或模型生成结果。

脱敏后的文字与原始实验输入有所不同，在这些文字上重新训练或推理应记为派生数据上的新运行。专家标准答案来自对原题的复核，并非本次复制时新增专家复核。保留日期和金额意味着本目录属于去标识化材料，不能据此声称已证明来源无法被重新识别。

`文件来源与校验.json`记录每个文件在脱敏复现包中的位置及对应指纹。`MANIFEST_SHA256.json`校验本数据目录的全部交付文件，清单自身除外。数据子目录里的原有`manifest.json`用于记录各实验的历史组织方式；涉及原工程路径和历史对象时，应结合来源清单解释，不能当成本目录的根文件清单。

代码、训练协议、评分脚本和模型指纹继续保留在完整的脱敏复现包中。本目录没有另行授予第三方数据再分发许可。
